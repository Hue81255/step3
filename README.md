Step 3. YOLOv8 콘크리트 결함 탐지 및 성능 평가


1. 문제 정의

YOLOv8s-Seg 모델을 이용하여 콘크리트 구조물에서 발생하는 결함을 탐지하고, 결함이 있는 영역을 구분하는 작업

탐지 대상은 균열(Crack), 백화(Efflorescence), 박리 및 탈락(Spall_detach)

2. 데이터

콘크리트 결함 이미지와 YOLO Segmentation 형식의 라벨 데이터를 사용

| 구분 | 이미지 수 |
| Train (학습 당시) | 4,036장 |
| Train (중복 데이터 분리 후) | 3,981장 |
| Validation | 40장 |
| Test (기존) | 40장 |
| Test (최종 평가) | 39장 |

데이터셋을 확인하는 과정에서 학습셋과 테스트셋에 같은 원본 이미지가 포함되어
학습 데이터에서 관련 이미지 55장을 분리하고, 테스트 데이터에서도 중복 이미지 1장을 제외함

3. 방법

YOLOv8s-Seg 모델을 사용

| 항목 | 설정 |
| Model | YOLOv8s-Seg |
| Epoch | 3 |
| Image Size | 960 |
| Batch Size | 4 |
| Optimizer | AdamW |
| Learning Rate | 0.00015 |
| Mosaic / Mixup | 0 / 0 |
| Seed | 42 |

학습이 완료된 후 저장된 `best.pt`를 사용하여 성능을 평가

세그멘테이션 성능은 Mask mAP50과 Mask mAP50-95로 평가

ON/OFF 평가는 이미지에 해당 결함이 있는지를 기준으로 진행했고 검증셋에서 F1 점수가 가장 높았던 임계값을 선택해 테스트셋에 적용함

4. 결과

최종 테스트 이미지 39장을 기준으로 평가한 결과

| 평가 방식 | 결과 |
| Mask mAP50 | 0.5931 |
| Mask mAP50-95 | 0.2838 |
| ON/OFF Macro F1 | 0.9077 |

세그멘테이션에서는 Spall_detach가 가장 높은 성능을 보였고, ON/OFF 평가에서는 Efflorescence가 가장 높은 F1 점수를 기록하였다.

5. 오류 분석

모델이 결함을 잘못 탐지한 FP와 실제 결함을 놓친 FN 사례를 존재

균열은 선을 균열로 잘못 탐지하거나, 실제 균열을 놓치는 경우

백화는 콘크리트 표면의 밝은 얼룩을 백화 현상으로 잘못 탐지

박리, 박락은 균열이나 구조물 경계를 박리·탈락으로 잘못 인식하거나, 표면이 손상된 부분을 탐지하지 못하는 경우가 존재


6. 한계

실습에서는 3 Epoch만 학습

최종 테스트 이미지도 39장으로 적은 편이기 때문에 특정 이미지들이 결과값에 영향을 주었을 수도 있음
